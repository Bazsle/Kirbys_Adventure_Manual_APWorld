# Kirby's Adventure Manual APWorld

Kirby's Adventure is a 2D platformer made by HAL Laboratory and published on the NES in 1993. You assume the role of the titular Kirby, who must reclaim the pieces of the Star Rod from King Dedede and his cronies and return tranquility and slumber to the world of Dream Land. While travelling across the 7 levels, Kirby can inhale his foes and get over 20 copy abilities that he can use as his own!

Checks:

Stage Clears (39 checks)

Big Switches (17 checks)

Bosses Defeated (8 checks + 1 GOAL check for the final boss)

Star Rod Piece Pick Ups (7 checks)

Sword (the one in Meta Knight's boss room, 1 check)

Copy Abilities (24 checks)

Arenas (5 checks)

Invincible Candy (5 checks)

1-Ups (43 checks, 37 normal, 6 expert)

Maxim Tomatos (34 checks)

Pep Drinks (30 checks)

Items:

Copy Ability (24): Every individual copy ability is it's own item in the pool and all are progression as assuming each one grants a check. The only ability you actually need to get to the end of the game is Sword as it is needed to fight Meta Knight.

Star Rod Piece (7): The seven colored pieces of the Star Rod are all individual hard-required items to reach the Fountain Of Dreams.

Progressive Level (7): This unlocks a new world (called a level in-game). For example, you need one Progressive Level in order to reach Ice Cream Island, two to reach Butter Building, etc. Vegetable Valley is open to you by default. You need all 7 of these to win.

Maxim Tomato, Pep Drink and Star are the filler items. 

1. To use this file, install the most recent version of the Archipelago launcher and the Archipelago Manual client.

2. After the AP launcher is installed, open it and install this apworld (or double-click the apworld file).

3. Close and re-open the AP launcher and select Generate Template Options to create a .yaml file for this game in the Templates directory. (note this will overwrite any customized .yaml files in that folder and generate for core-verified worlds and installed custom worlds)

4. This manual APWorld has a few customizable toggles within the YAML file.

  a. 1-Up-Sanity (adds 37 1-Up locations to the pool)
  
  b. 1-Up-Sanity Expert (adds 6 additional 1-Up locations that are tough for the average player to reach)
  
   i. If you want these tougher locations to be enabled, set both 1-Up Sanity and 1-Up Sanity Expert to true in your YAML. If you leave this option off or the normal 1-Up Sanity off, these checks will not be enabled.
  
  c. Tomato-Sanity (adds 34 Maxim Tomato locations to the pool, note this includes the 5 Maxim Tomato rewards in the mini-boss arenas)
  
  d. Drink-Sanity (adds 30 Pep Drinks locations to the pool)

6. Of course, be sure to change your slot name to whatever you want it to be called.

7. Send the .apworld file and the .yaml file to the host who will generate the multiworld game if you are not hosting the game yourself. (skip to step 11 if you are not hosting)

8. If you are hosting the game yourself, move the .yaml into the Players directory (in addition to any other players' .yaml files) in your Archipelago installation folder.

9. Click on the ArchipelagoGenerate.exe in your AP installation or select Generate in the AP Launcher to create the multiworld.

10. Once the output ZIP file is generated, go to archipelago.gg and select Host Game and upload the output ZIP file there.

11. Download a spoiler log if you want and click Create Room to get the room opened and visibility to the port number for your game.
  a. Note that you do not need to download the patch file associated with your slot to play this game.

12. Open the AP Manual client (I also recommend opening a text client to more easily follow along with sent items), enter the port number and your slot name and enjoy!
